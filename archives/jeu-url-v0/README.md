# Premier jeu PhishDojo (archive)

Le jeu d'origine, construit avec le classifieur d'URL de [`ml/`](../../ml/) : défis URL (légitime ou imitation ?), duel contre les vrais scores du modèle LightGBM, situations mail et pièce jointe, ceintures, avatar, classement local, français et anglais.

Il est conservé ici tel qu'il était, comme matière première pour le Dojo (phase C de la feuille de route). **Il n'est pas publié** : seul le dossier `web/` est déployé, et ce code ne respecte pas encore les règles du site (CSP stricte, aucune ressource tierce, masquage). La vidéo et le GIF de la bande-annonce (13 Mo) ne sont pas versionnés.
