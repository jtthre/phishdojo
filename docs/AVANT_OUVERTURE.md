# Avant d'ouvrir la collecte au public

Tant qu'une case reste vide :

- `npm run rappel` l'affiche, et Claude le rappelle au début de chaque séance de travail ;
- le déploiement publie le site en **mode démonstration**, même si la base est configurée ;
- seule la variable de dépôt `MODE_TEST=1` permet de brancher la base pour des essais, avec une bannière « version de test » sur la page.

Pour valider un point, remplace `[ ]` par `[x]` et ajoute la date et une preuve courte (lien, nom des relecteurs, numéro de récépissé).

- [ ] **Lecture de capture testée sur un vrai téléphone** : Android d'entrée de gamme, capture d'un SMS et d'une conversation WhatsApp ; le texte est extrait, l'image n'est pas envoyée (onglet Réseau du navigateur ou test sans connexion après chargement).
- [ ] **Wolof relu par deux locuteurs natifs** : toutes les lignes de `docs/RELECTURE_WOLOF.md` ont « OK » ou une correction reportée dans `web/i18n.js`.
- [ ] **Déclaration du traitement auprès de la CDP** : déclaration déposée (et, si la CDP le demande, autorisation pour l'hébergement hors du Sénégal).
